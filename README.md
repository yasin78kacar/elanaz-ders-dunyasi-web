# Ders Dünyası
İlkokul 1-4. sınıf öğrencileri için ücretsiz, reklamsız eğitim uygulaması.
MEB müfredatına uygun sorular, hikâyeler, boyama köşesi ve mini oyunlar içerir.
Canlı: https://yasinkacar.com
## Teknoloji
React + TypeScript + Vite. Tüm veriler yalnızca kullanıcının cihazında (localStorage) saklanır;
hiçbir veri dışarı gönderilmez, hesap veya üyelik gerekmez.
## Geliştirme
```
npm install
npm run dev
npm run build
```
